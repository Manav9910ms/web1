# ALPS Makeup Studio & Academy — Website Preview

Premium, mobile-first concept for ALPS Makeup Studio & Academy, Vikas Marg, East Delhi.

## Included
- Luxury bridal-focused visual system
- Service, academy, gallery, reviews and contact sections
- WhatsApp-first enquiry flow
- Mobile navigation and scroll reveal animation
- Local SEO metadata + BeautySalon structured data
- `robots.txt` and custom favicon

## Before client launch
1. Replace the Unsplash concept images with ALPS-approved original photos.
2. Confirm the business phone, official social links, exact operating hours and ownership/branding.
3. Add the final production domain in canonical/OG URLs and generate a sitemap for that domain.
4. Replace the sample review quotes with approved review excerpts or a live review integration.
5. Connect the final domain to GitHub Pages/hosting and test WhatsApp, calling, Maps and form behaviour on mobile.
